# Import dans draw.io

Utilise les fichiers `.drawio` ci-dessous. Ils contiennent déjà la structure XML native de draw.io, donc le diagramme se crée automatiquement à l’import.

- `class-diagram.drawio`
- `use-case-diagram.drawio`
- `sequence-diagram.drawio`

Dans draw.io:
1. `File` > `Import From` > `Device`
2. Sélectionne le fichier `.drawio`
3. Le diagramme s’ouvre directement avec les formes et les liens
